How to set GIF as wallpaper on your PC

Updated October 30, 2026

Windows will accept a GIF as a background, then show it as a still picture. To keep it moving, you need one small free app.

Set GIF as wallpaper on Windows 11

If you choose a GIF in the Windows background settings, you get a still picture. To see it move, play it through an app that runs behind your icons.

  1. Download the ZIP from SourceForge, extract it and run the app.
  2. Drag your GIF onto the window to set it. You can also click Add Wallpaper and choose the file.
  3. The GIF starts playing on your desktop.

The steps are the same if you want to set a GIF as wallpaper on Windows 10.

Choosing a GIF that looks good

A GIF stretched across a large monitor shows every flaw, so start from the largest version you can find. If you only have a small one, a video of the same scene will usually look sharper. Here is how to set a video as wallpaper.

Common questions

Can you set a GIF as wallpaper on Windows 11 without an app?

You can pick a GIF in the background settings, but Windows shows it as a still picture. To keep it moving, you need an app that plays it.

Can I set a GIF as wallpaper on Windows 10?

Yes. The steps are the same on Windows 10 and Windows 11.

Will a GIF wallpaper drain my laptop battery?

Playback pauses by itself when the laptop runs on battery, keeping CPU and GPU usage near zero.

Does a GIF wallpaper work with two monitors?

Yes. The app has multi-monitor support.
